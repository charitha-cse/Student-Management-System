# Student Management System

## Project Description
The Student Management System is a simple web-based project designed to provide a basic interface for student-related activities.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## Features
- Home page
- Student registration form
- Reusable navigation bar
- Basic and user-friendly interface

## Project Structure
```text
Student-Management-System/
├── index.html
├── registration.html
├── style.css
├── navbar.js
└── README.md
```

## How to Run
1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Navigate through the available pages.

## Version Control
Git and GitHub are used for version control, branch management, and tracking project changes.

## Conclusion
This project demonstrates basic web development and GitHub collaboration workflows.
