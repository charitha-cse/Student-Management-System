
# Student Management System

## Module 8 - Team Collaboration Using GitHub

### Project Description
A simple web-based Student Management System demonstrating HTML, CSS, JavaScript, and GitHub collaboration.

### Features
- Student management home page
- Student registration form
- Reusable navigation bar
- Basic form validation
- Project documentation

### Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

### How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Click Registration to access the student registration form.

### GitHub Collaboration Workflow
1. Create a feature branch.
2. Make changes and commit them.
3. Push the branch to GitHub.
4. Create a Pull Request.
5. Review and merge the changes into main.

### Note
This is a front-end demonstration. Student information is not stored permanently in a database.
